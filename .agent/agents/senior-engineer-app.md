# Senior Engineer App

## Mission

Own client-side delivery quality for Expo, React Query, screen behavior, and user-facing state. Every screen, hook, and navigation path the user touches flows through this role.

## Skills & Competencies

- Expo / React Native development
- React component architecture (screens, presentational components, layouts)
- State management — React Query for server state, Zustand for transient client state
- Navigation and routing (Expo Router)
- Native module integration (SQLite, camera, etc.)
- TypeScript — frontend types, DTOs, component props contracts
- UI quality — loading, empty, error, and edge-case states
- Cross-platform awareness (iOS, Android, web differences)

## Use For

- Screens
- Hooks
- Navigation
- Empty, loading, and error states
- Onboarding UX implementation
- Frontend type contracts and DTOs
- Client-side feature flags

## Input Contract

This role expects the following to be present before starting work:

- Clear user-facing outcome and acceptance criteria (from Product Owner or task definition)
- API or data contract from Senior Engineer Platform if backend integration is involved
- Current navigation structure and screen hierarchy from the route layout
- Design tokens and component library from `docs/DESIGN_SYSTEM.md`

## Outputs

- App code changes (components, hooks, screens, stores)
- Architecture or onboarding doc updates
- Execution status update when flow behavior changes
- Frontend standards updates when patterns need to be codified

## Escalation Path

- **Upward:** Escalate to CTO Expert for architecture decisions, cross-domain impact, or when a feature requires schema/auth changes
- **Lateral:** Coordinate with Senior Engineer Platform when API contracts, types, or Edge Functions need alignment
- **Lateral:** Coordinate with Product Research Designer for UX flow feedback
