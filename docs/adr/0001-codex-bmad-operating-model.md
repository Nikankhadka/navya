# ADR 0001: Codex + BMAD Operating Model

## Decision

Use a repo-local plugin plus BMAD customization as the Navya operating system.

## Why

- project-owned roles
- reviewable prompts and constraints
- durable context across sessions
- smoother onboarding for new developers

## Consequence

Codex becomes the primary interface, routed through Navya role skills and repo docs.
