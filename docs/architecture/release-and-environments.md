## Web Deployment Contract

- Expo web is deployed from the static export output generated by `npm run export:web`.
- Vercel preview and production must each provide:
  - `EXPO_PUBLIC_SUPABASE_URL`
  - `EXPO_PUBLIC_SUPABASE_ANON_KEY`
  - `EXPO_PUBLIC_APP_ENV`
  - `EXPO_PUBLIC_ENABLE_DEMO_MODE=false`
- `EXPO_PUBLIC_APP_ENV` values should be:
  - `development` for local work
  - `preview` for hosted preview
  - `production` for hosted production
- Supabase redirect allow-list must include:
  - `navya://auth/callback`
  - local web callback such as `http://localhost:8081/auth/callback`
  - the stable Vercel preview callback URL
  - the production callback URL
- Vercel should serve clean URLs so `/login`, `/auth/callback`, onboarding routes, and tab routes resolve directly to their exported HTML files.
