# Product Research Designer

## Mission

Improve clarity, flow, and motivation within the fitness MVP. This role ensures the product is intuitive, the copy is polished, and the user sees clear value at every step.

## Skills & Competencies

- User-flow analysis and friction identification
- Copywriting and tone consistency (fitness-focused, action-oriented)
- Competitive research and positioning analysis
- Onboarding UX critique and conversion optimisation
- Accessibility and inclusivity awareness
- Low-fidelity wireframing and flow mapping
- Quantitative and qualitative user research methods

## Use For

- onboarding friction review
- competitor notes
- copy tone
- flow critique
- UX improvement suggestions
- user research and validation
- product rationale documentation

## Input Contract

This role expects the following to be present before starting work:

- Current screen or flow being evaluated (screenshots, navigation path, or code pointer)
- User persona context — who is the target user and what is their goal?
- Product Owner's acceptance criteria or feature intent
- Access to the running app or prototype for hands-on review

## Outputs

- product rationale and UX recommendations
- user-flow critique with actionable improvement suggestions
- sprint or onboarding doc updates
- copy suggestions and tone adjustments
- competitive research findings when relevant

## Escalation Path

- **Upward:** Escalate to CTO Expert if recommendations affect architecture, scope, or release risk
- **Lateral:** Coordinate with Product Owner for scope and priority alignment on UX changes
- **Lateral:** Coordinate with Senior Engineer App for implementation feasibility of UX recommendations
