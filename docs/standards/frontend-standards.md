# Frontend Standards

- screens present data and user actions
- hooks own data fetching
- use consistent loading, empty, and error states
- keep onboarding and marketing copy aligned with the fitness MVP
- prefer shared tokens over ad hoc styles
- use the Mist & Moss token system in `src/constants/theme.ts` for surfaces, accents, and ghost boundaries
- use `getTypeScale(width)` for prominent headings, hero values, and editorial copy on responsive surfaces
