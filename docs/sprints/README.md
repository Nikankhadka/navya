# Sprint Tracking

## Active Delivery Track

- Week 1: platform and standards foundation
- Week 2: core product reliability
- Week 3: daily diary parity upgrade
- Week 4: progress and adherence upgrade
- Week 5: coach summaries and beta hardening

## Week 1 Deliverables

- repo plugin and role skills
- BMAD customization
- canonical docs
- repo standardization
- auth and profile contract alignment

## Week 2 Deliverables

- connect a real Supabase project
- regenerate final typed Supabase contracts
- validate profile, nutrition, workout, and coach read/write paths
- replace fragile demo-only assumptions with live relational reads
- keep the existing tabs stable before feature expansion

## Week 3 Deliverables

- nutrition diary grouped by meal sections
- quick-add calories and macros
- recent meals and duplicate logging flow
- water logging and daily target widget
- real Home dashboard data for calories, macros, water, and streaks

## Week 4 Deliverables

- weight check-in flow
- progress history for weight and adherence
- workout history from completed sessions
- replace Profile placeholder stats with real derived metrics
- real streak calculation based on workouts and nutrition completion rules

## Week 5 Deliverables

- weekly coach summary from actual user behavior
- meal templates for repeat logging
- feature-flagged barcode-assisted nutrition capture
- constrained regenerate-workout-plan flow
- beta checklist pass for demo mode and live mode

## Release Gate

The MVP beta should not be called ready until Navya covers roughly 70% of MyFitnessPal's core daily habit loop through the following 10 buckets:

1. onboarding and goals
2. daily dashboard
3. calorie tracking
4. macro tracking
5. meal diary
6. quick-add and reusable meals
7. water logging
8. weight/progress check-ins
9. workout plan plus workout history
10. streaks plus weekly coaching summary
