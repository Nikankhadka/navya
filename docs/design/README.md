# Navya Design Docs

This folder holds the implementation-facing design definition for the current fitness MVP.

## Files

- `forest-motion.md`: shared visual system, tokens, material rules, motion defaults, and component guidance
- `routes.md`: route-by-route page specs for every current MVP route plus the main overlay states

## Scope Rules

- follow the current route map exactly
- keep all new MVP work inside existing tabs or modal states
- preserve mobile-first behavior across native and the constrained web shell
- align with `docs/mvp/README.md`, `docs/sprints/README.md`, and `docs/onboarding/user-flow-test-plan.md`
